# Pavan Kumar - AI Systems Portfolio

A clean, responsive portfolio website built with React, Vite, and Tailwind CSS, highlighting Gen AI, Clinical NLP, RAG Architectures, and LLM Engineering projects.

---

## 🚀 Easy GitHub Pages Hosting (2 Simple Steps)

This project is 100% client-side and requires zero server configuration or database setup.

### Option A: Automatic GitHub Actions (Recommended)
1. Push this repository to GitHub (`main` or `master` branch).
2. Go to your repo on GitHub -> **Settings** -> **Pages**.
3. Under **Build and deployment** -> **Source**, choose **GitHub Actions**.
4. The site will automatically build and deploy within 1 minute at `https://<your-username>.github.io/<repo-name>/`.

---

### Option B: Local Build & Manual Push
```bash
# 1. Install dependencies
npm install

# 2. Build production static files
npm run build

# The output is in the /dist folder ready to be hosted anywhere.
```

---

## 🛠️ Customizing Your Links & Information
- Edit `/src/data/portfolioData.ts` to update your name, email, GitHub/LinkedIn URLs, and project details.
- Or use the on-screen **Settings (⚙️)** button in the live app to update your social links.
